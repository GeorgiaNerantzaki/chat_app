This project is a real-time chat application that enables users to communicate instantly through a web interface.

Features-->
Real-Time Messaging: Users can send and receive messages instantly.
User Authentication: Secure login and registration system.
Chat Rooms: Support for multiple chat rooms or channels.
Online Status: Display of online users.


Technologies Used-->
Architecture:Model View Controller
Frontend: Bootstrap(HTML/CSS
Backend: Python, Flask
Database: SQLite(RDBMS)
